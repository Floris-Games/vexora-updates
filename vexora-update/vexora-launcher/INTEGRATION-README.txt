VEXORA + SILVER ROAD

Silver Road is bundled directly in the Vexora launcher.
Double-click BUILD-SETUP.bat on Windows to build the installer (Node.js required).
The installer will be in the dist folder.
Log in to Vexora as before, select Silver Road, and click PLAY GAME.
The game opens in its own window. No GitHub game manifest or game download is required.
Existing Supabase authentication files were preserved from the verification-code fix.
The game is the supplied game.html.
